# 3D-model

A fingerboard 3D model used as advertising inventory.

## Concept

Event marketing has a running trend of people selling logo placements on
whatever surface they'll be carrying around a conference — hoodies, hats,
laptop lids, foreheads. This is the same pitch applied to a fingerboard, played
completely straight: a real rate card, a real spec sheet, real millimeter
measurements, and a CPM that is roughly 150× the Super Bowl's.

The 3D model is the production tool behind it. It renders sponsor logos onto
the deck, trucks, and wheels so buyers can see their placement before they
commit, and so every post has art attached.
